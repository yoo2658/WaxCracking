# 왁스 뿌수기 (Wax Cracking)

사진이나 색을 입힌 슬라임/스퀴시에 왁스 껍질을 씌우고, 눌러서 갈라뜨리며 속을 드러내는 미니 웹 토이입니다. Three.js 기반이며 서버 없이 정적 파일만으로 동작합니다.

## 로컬 실행
```
npm install
npm run build
```
`index.html`을 브라우저로 열면 바로 동작합니다(오프라인 가능).

## 플레이
- 클릭: 왁스에 크랙이 갈라지며 안쪽이 비침. 같은 곳을 두 번 누르면 조각이 떨어져 나감.
- 드래그: 시점 회전.
- 재질(스퀴시/슬라임), 사진/색 등록, 리셋은 화면 우측 패널에서 조작.
